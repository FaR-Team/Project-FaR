# FaR Notes ("Forked" Vlyx's notes)

FaR Notes lets you create and manage contextual notes directly inside the Unity Scene View.

## How to Use

1. Open your **Scene View**.
2. Locate the **"FN"** overlay button (formerly SN). If you can't find it, press on  `⋮` -> **Overlay** -> FaR Notes.
3. Click **FaR Notes**.
4. Press **Create Note**.
5. Click anywhere in the Scene to place the note  
   *(You can reposition it later if needed.)*
6. Write your note in the Inspector.
7. Click **Apply Changes** to save.

## Editing a Note

- Select an existing note.
- Click **Enable Editing**.
- Modify the text, category, status, or position.
- Click **Apply Changes** to save.

## Customizing Your Inspector

- On top bar, Go **FARUtils → FaR Notes → Style Settings**
- On the Open Window customize the inspector as you need.

## Managing Notes

- Use the overlay filters to control which categories are visible.
- Notes support comments, status tracking, and categorization.
- You can delete individual notes from the Inspector.
- Use **FARUtils → FaR Notes → Delete All Notes** to remove all notes in the current scene.
